# UI/UX Design

Create interfaces with clear structure, visual hierarchy, intuitive navigation, and excellent usability.

## Information Architecture

- **Hierarchy**: Content organized from most to least important
- **Chunking**: Group related information together
- **Progressive disclosure**: Show only what's needed at each step
- **F-pattern / Z-pattern**: Align with natural scanning behaviors

## Navigation

- Max 7±2 main navigation items
- Consistent placement across all pages
- Clear current page indication
- Breadcrumbs for deep hierarchies
- Search functionality for content-heavy sites
- Mobile: hamburger menu or bottom nav for thumb reach

## User Flows

- Minimize steps to complete core tasks (3-click rule as guidance)
- Clear call-to-action on every page
- Provide feedback for every user action
- Handle errors gracefully with recovery paths
- Show progress for multi-step processes

## Visual Hierarchy

1. Size and weight for primary elements
2. Color and contrast for emphasis
3. Spacing and proximity for grouping
4. Typography scale for content levels
5. Icons and imagery for visual anchors

## Interaction Patterns

- Buttons: immediate visual feedback on click/hover
- Forms: inline validation, helpful error messages
- Loading: skeleton screens over spinners when possible
- Transitions: 200–300ms ease-out for most animations
- Touch targets: minimum 44×44px for mobile

## Usability Principles

- **Visibility**: Important actions should be visible, not hidden
- **Affordance**: Interactive elements should look clickable/tappable
- **Consistency**: Same action = same UI pattern everywhere
- **Recovery**: Undo, back, and clear options always available
- **Recognition**: Use familiar patterns over novel ones

## Mobile-First

- Design for smallest screen first, then enhance
- Thumb-friendly tap targets
- Simplified layouts for vertical scrolling
- Avoid hover-dependent interactions on mobile
