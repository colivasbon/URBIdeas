# Landing Page Design

Create focused pages oriented toward a single action, eliminating unnecessary sections.

## Page Structure (Required Sections)

### 1. Hero Section
- Headline: Clear value proposition (what + benefit) in ≤10 words
- Subheadline: Expand on the value in 1–2 sentences
- Primary CTA: One prominent button with action text
- Visual: Product screenshot, illustration, or hero image
- Avoid: Carousels, vague taglines, multiple competing CTAs

### 2. Social Proof
- Logos of clients/partners (if B2B)
- Testimonials with real names, photos, roles
- Numbers: "10,000+ users" or "4.9★ rating"
- Case study snippets with results
- Place early (below hero) for credibility

### 3. Features / Benefits
- 3–4 key features maximum
- Benefit-first headlines (not feature-first)
- Icon + short description format
- Group related features together
- Use visuals (screenshots, diagrams) over text

### 4. How It Works
- 3-step process maximum
- Numbered steps with clear actions
- Visual representation of the flow
- Reduces cognitive friction

### 5. Pricing (if applicable)
- Clear pricing tiers
- Highlight recommended plan
- Feature comparison table
- Annual/monthly toggle with savings shown

### 6. Final CTA
- Repeat the primary action
- Create urgency (limited time, waitlist, etc.)
- Minimal distractions around the CTA

## Sections to Avoid

- ❌ About us / company history (not on landing pages)
- ❌ Blog previews or news
- ❌ Complex navigation menus (simplify to 3–4 items)
- ❌ Footer overload (keep minimal)
- ❌ Multiple CTAs competing for attention
- ❌ Auto-playing videos or intrusive popups

## Conversion Optimization

- One page = one goal = one primary CTA
- CTA button: high-contrast color, action-oriented text ("Start Free", "Get Access")
- above-the-fold CTA always visible
- Reduce form fields to absolute minimum
- Mobile: CTA sticky at bottom of viewport
- Page load under 3 seconds

## Layout Patterns

```
[Nav: Logo | 3 links | CTA button]

[Hero: Headline + Subtext + CTA + Image]

[Logos / Social proof bar]

[Features: 3 columns with icons]

[How it works: 3 steps]

[Testimonials: 2–3 cards]

[Pricing: tier cards]

[Final CTA section]

[Minimal footer]
```
