# Sistema de diseño aplicado

Identifica primero variables, componentes y patrones existentes. Reutilízalos cuando sean buenos. Define un conjunto pequeño y documentado de colores, tipografía, tamaños, anchuras, espaciados, radios, bordes, iconos y niveles de énfasis. Incluye reglas para fondos claros y oscuros solo si ambos existen o hacen falta.

Diseña familias de componentes según su función: navegación, búsqueda, filtros, datos tabulares, paneles, formularios, alertas y fichas. Explica cuándo un dato necesita tabla y cuándo merece una visualización o una tarjeta; evita convertir todo en el mismo bloque. Conserva densidad suficiente para tareas frecuentes y aumenta claridad sin alargar artificialmente las páginas.

Especifica estados: reposo, hover, foco visible, activo, deshabilitado, cargando, vacío, éxito y error. Ajusta anchuras al contenido real; evita textos cortados o superpuestos y columnas demasiado estrechas. Comprueba escritorio, tablet y móvil, incluyendo contenido largo, zoom y navegación con teclado.

Propaga los cambios a componentes compartidos antes de corregir página por página. No crees una librería paralela si la existente puede adaptarse. Deja una nota de decisiones visuales en el proyecto solo si aporta valor y no duplica documentación existente.
