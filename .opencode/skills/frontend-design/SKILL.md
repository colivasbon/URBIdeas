# Frontend Design

Design beautiful, modern, and aesthetically polished frontend interfaces. Avoid generic-looking websites.

## Core Principles

- **Visual hierarchy**: Guide the user's eye with size, color, spacing, and typography contrast
- **Whitespace**: Use generous whitespace to create breathing room and reduce cognitive load
- **Consistency**: Maintain uniform patterns across all components
- **Micro-interactions**: Add subtle animations for hover states, transitions, and feedback
- **Modern aesthetics**: Follow current design trends (glassmorphism, gradients, rounded corners, soft shadows)

## Typography

- Use no more than 2 font families (one for headings, one for body)
- Establish a clear type scale (e.g., 12/14/16/20/24/32/48px)
- Ensure line-height is 1.5x–1.75x for body text
- Use font-weight contrasts for hierarchy (400 body, 600–700 headings)

## Color

- Primary palette: 1 main color + 2–3 accent variations
- Neutral palette: 3–5 shades for text, backgrounds, borders
- Ensure WCAG AA contrast ratios (4.5:1 for text, 3:1 for large text)
- Use color intentionally for actions, states, and hierarchy

## Spacing & Layout

- Use a consistent spacing scale (4px base: 4, 8, 12, 16, 24, 32, 48, 64)
- Grid-based layouts with clear column gutters
- Max content width of 1200px for readability
- Responsive breakpoints: mobile-first approach

## Components

- Buttons: clear visual weight, hover/active states, loading states
- Cards: subtle shadows, consistent padding, hover elevation
- Forms: clear labels, inline validation, accessible focus states
- Navigation: sticky/fixed when appropriate, clear active states

## Anti-patterns to Avoid

- Walls of text without visual breaks
- Poor contrast or illegible font sizes
- Inconsistent spacing or alignment
- Excessive animations that slow the interface
- Generic Bootstrap/Material look without customization
