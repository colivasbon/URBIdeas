# Brand Guidelines

Translate a business's identity into the web, maintaining visual and tonal consistency.

## Brand Identity Mapping

### Colors
- Primary brand color → main CTAs, headers, key accents
- Secondary colors → supporting elements, backgrounds, tags
- Neutral palette → text, borders, backgrounds
- Apply 60-30-10 rule: 60% neutral, 30% primary, 10% accent

### Typography
- Brand font → headings and display text (if web-safe or available via Google Fonts/embed)
- Fallback → system font stack that matches the brand's character
- Match the brand's tone: serif for traditional/luxury, sans-serif for modern/tech

### Logo Usage
- Minimum clear space around logo (typically 1.5x logo height)
- Minimum display size (typically 80–120px width)
- Use SVG when possible for crisp rendering
- Provide dark/light variants for different backgrounds
- Never stretch, rotate, or add effects to the logo

## Brand Voice & Tone

- Define writing style: formal vs. casual, technical vs. approachable
- Use consistent terminology across the site
- Headlines: active voice, concise, action-oriented
- Body text: match brand personality (friendly, professional, authoritative)
- CTAs: use brand-specific action words

## Visual Expression

### Photography & Imagery
- Consistent filter/treatment for all images
- Subject matter that reflects brand values
- Avoid generic stock photos — prefer authentic imagery
- Illustration style (if applicable): consistent line weight, color palette, detail level

### Icons
- Use a single icon set (outlined OR filled, not mixed)
- Consistent size grid (16px, 20px, 24px, 32px)
- Match brand personality: rounded for friendly, sharp for professional

### Spacing & Layout
- More whitespace = more premium feel
- Dense layouts = more information-driven, utilitarian feel
- Align layout choices with brand positioning

## Application Checklist

- [ ] Colors match brand palette exactly
- [ ] Typography reflects brand character
- [ ] Logo used correctly with proper spacing
- [ ] Imagery aligns with brand style
- [ ] Writing tone matches brand voice
- [ ] Consistent icon style throughout
- [ ] Overall feel matches brand positioning
